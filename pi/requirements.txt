# Pi publisher. Python 3.9 on Raspberry Pi OS Bullseye.
#
# The VL53L7CX driver is not on PyPI. ST's VL53L7CX is driver-compatible
# with the VL53L5CX, so install this pure-Python port of the ST ultra-lite
# driver (it talks I2C through smbus2, no C build):
#
#   pip install "vl53l5cx @ git+https://github.com/Abstract-Horizon/vl53l5cx_python.git"
#
# The USB-Ethernet link on this Pi has no route to the internet. Copy the
# wheels and that git checkout from a machine that does, then:
#
#   pip install --no-index --find-links /path/to/wheels -r requirements.txt
#   pip install --no-deps /path/to/vl53l5cx_python
#
# See the project README for the exact commands.

# collect_data.py and runtime.py use only this list, the VL53 driver, and
# the Python standard library. Audio is `aplay` (already on the Pi) or
# sounddevice if it happens to be installed. Do not add numpy or
# scikit-learn here: the USB link cannot reach PyPI, and gait inference
# is a dot product in gait.py.
